# Skin Beauty Método — landing page

Landing page do curso presencial de clareamento íntimo **Skin Beauty Método**, com Ana Paula Alves de Souza (Ana Paula Estética, Savassi · BH).

## Estrutura
- `index.html` + `assets/` — site publicado (estático, sem build).
- `_headers`, `vercel.json`, `.htaccess` — cache para Netlify, Vercel e Apache.
- `fonte/` — arquivos de origem e scripts que geram o `index.html`.

## Publicação
GitHub Pages: Settings → Pages → *Deploy from a branch* → `main` / `(root)`.

## Antes de divulgar
No `index.html`, procure `CONFIG` e preencha o WhatsApp comercial e o webhook das candidaturas. Veja também o `LEIA-ME.txt`.
